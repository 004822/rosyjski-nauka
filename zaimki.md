# Zaimki (osobowe i pytajne)

Ta sekcja zawiera wykaz zaimków osobowych oraz zaimków pytajnych w języku rosyjskim.

---

#### 1. Zaimki osobowe i ich odmiana (Biernik / Dopełniacz)

| Znaczenie       | Zaimek (Mianownik) | Biernik / Dopełniacz |
|:--------------- |:------------------ |:-------------------- |
| ja              | **Я**              | **Меня**             |
| ty              | **Ты**             | **Тебя**             |
| on              | **Он**             | **Его** *(wym. Ewo)* |
| ona             | **Она**            | **Её**               |
| ono             | **Оно**            | **Его** *(wym. Ewo)* |
| my              | **Мы**             | **Нас**              |
| wy / Pan / Pani | **Вы**             | **Вас**              |
| oni / one       | **Они**            | **Их**               |

##### Praktyczne przykłady w zdaniach:
* `Меня зовут Анна.` *(Mam na imię Anna.)*
* `Я тебя знаю.` *(Znam cię.)*
* `Мы их ждём.` *(Czekamy na nich.)*
* `У меня есть вопрос.` *(Mam pytanie. / U mnie jest pytanie.)*

---

#### 2. Zaimki pytajne (Pytania podstawowe)

| Zaimek rosyjski                    | Znaczenie po polsku         | Przykładowe użycie i zdanie                                               |
|:---------------------------------- |:--------------------------- |:------------------------------------------------------------------------- |
| **Кто?**                           | Kto?                        | `Кто это?` *(Kto to jest?)* → `Это мой друг.` *(To jest mój przyjaciel.)* |
| **Что?**                           | Co?                         | `Что это?` *(Co to jest?)* → `Это книга.` *(To jest książka.)*            |
| **Где?**                           | Gdzie? *(miejsce)*          | `Где ты?` *(Gdzie jesteś?)* → `Я дома.` *(Jestem w domu.)*                |
| **Куда?**                          | Dokąd? *(cel ruchu)*        | `Куда ты идёшь?` *(Dokąd idziesz?)* → `Я иду в парк.` *(Idę do parku.)*   |
| **Откуда?**                        | Skąd?                       | `Откуда ты?` *(Skąd jesteś?)* → `Я из Польши.` *(Jestem z Polski.)*       |
| **Когда?**                         | Kiedy?                      | `Когда урок?` *(Kiedy jest lekcja?)* → `Завтра.` *(Jutro.)*               |
| **Почему?**                        | Dlaczego?                   | `Почему ты молчишь?` *(Dlaczego milczysz?)*                               |
| **Как?**                           | Jak?                        | `Как дела?` *(Jak leci? / Co słychać?)*                                   |
| **Сколько?**                       | Ile?                        | `Сколько это стоит?` *(Ile to kosztuje?)*                                 |
| **Какой / Какая / Какое / Какие?** | Jaki / Jaka / Jakie / Jacy? | `Какая сегодня погода?` *(Jaka jest dzisiaj pogoda?)*                     |
